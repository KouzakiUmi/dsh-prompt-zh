## banner.svg

横幅是手工编写的 SVG 说明图，不是 DSH 界面截图，也不描述不存在的设置页。

- 左侧主标题按要求写为“让Deepseek使用中文回复”，分两行排版；这是语言引导目标，不是跨模型效果保证。列出系统段落、MCP 指导与已知运行时注入，并注明其他模型的语言遵循情况可能不同。
- 右侧对照严格来自 `translate('harness:identity', 'You are an AI agent powered by DeepSeek Harness.')` 的输出。
- 图中保留“未知内容不猜译”和“不承诺全量请求中文化”的边界；具体未覆盖场景见 [兼容性文档](../docs/compatibility.md)。
- 只引用字体，不复制、下载或嵌入字体文件；首选现场已确认安装的 `Sarasa UI SC` / `Noto Sans SC`，并保留系统无衬线兜底。远端渲染器字体环境不同，不能保证逐像素一致。
- SVG 无脚本、外部字体、外部图片或网络依赖。README 的远端图片访问属于文档阅读，不是插件运行时联网。

更改示例时，应先运行纯函数和离线测试确认译文。原文或实现变化后同步 SVG、README 和断言；不要为了视觉效果臆造业务事实。
